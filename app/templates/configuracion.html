1. En el reloj

  1. Entrá al menú con un usuario administrador y abrí Comunicación → Config SVR de nube (en inglés, Cloud Server Setting).
  2. Modo del servidor: ADMS. Si pregunta por nombre de dominio, dejalo desactivado.
  3. Dirección del servidor: {{ ips[0] if ips else "la IP de esta PC" }} · Puerto: {{ puerto }}. Proxy: desactivado.
  4. Guardá. En unos segundos el indicador de la barra de arriba tiene que decir Reloj conectado; si no, reiniciá el reloj.

Los nombres del menú pueden variar un poco según el firmware del reloj.

2. En esta PC (una sola vez)

Abrí PowerShell como administrador (clic derecho en Inicio → Terminal (administrador) o Windows PowerShell (administrador)) y pegá cada comando.

3. Para que siga andando

  • IP fija: el reloj apunta a una IP. Pedí en el router una reserva DHCP para esta PC; si la IP cambia, hay que volver a cargarla en el reloj.
  • Este programa abierto: el reloj guarda las marcaciones mientras la PC está apagada y las manda todas juntas cuando vuelve. Para que arranque solo al prender la PC: clic derecho en el ícono del reloj en la bandeja (al lado de la hora de Windows) → Iniciar con Windows.
  • Primera vez: Windows puede preguntar si permite el acceso de mini-asistencia a la red. Marcá Redes privadas y tocá Permitir.
  • No abrir ZKBio Time a la vez: usan el mismo puerto y el reloj le hablaría a uno solo.
  • Hora del reloj: revisá que coincida con la de la PC (menú Sistema → Fecha y hora).
